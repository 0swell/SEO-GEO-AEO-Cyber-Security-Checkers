## 🚀 Kullanım

1. Paketi yeni projeye kopyala.
2. `0-BASLA.md`'yi oku; `CLAUDE.md`'deki `{{...}}` alanlarını doldur (tahmin edilmez, sorulur).
3. Konu verilince `KONU-VERILDIGINDE.md` akışını izle.
4. Geliştirme boyunca checklist'lere uy; yayın öncesi + sonrası denetle.

## 🎯 Neyi garanti eder?

- **SEO / GEO / AEO** baştan gömülü — sonda toplu düzeltme yok, geliştirme sırasında şartname.
- **%100 statik (SSG)** → hız (LCP) + YZ botlarının JS'siz okuyabilmesi.
- **Güvenlik** checklist'i geliştirme boyunca; canlı site ayrıca denetlenir.
- **Rol ayrımı:** yazan ≠ test eden ≠ denetleyen (kendi işini test eden körleşir).
